# 협동 인형뽑기 (Cooperative Claw Machine)

4명이 함께 플레이하는 웹 기반 협동 인형뽑기 게임입니다. 각 플레이어가 하나의 방향키를 담당하여 집게를 조작하고, 미로를 탐색해 인형을 뽑습니다.

## 게임 개요

- **플레이어**: 4인 협동 (각자 상/하/좌/우 방향 하나 담당)
- **난이도**: 1~30 레벨, 4레벨 간격으로 난이도 변화
- **Phase 1**: 위에서 내려다보는 시점으로 미로 속 인형에 집게를 이동
- **Phase 2**: 옆에서 보는 시점으로 집게를 하강시켜 인형 집기
- **최종 확률**: Phase 1 겹침 비율(A) x Phase 2 겹침 비율(B)로 성공 여부 결정

## 기술 스택

| 분류 | 기술 | 설명 |
|------|------|------|
| **모노레포** | pnpm workspaces | 패키지 간 의존성 관리 |
| **프론트엔드** | Vite + React 19 + TypeScript | UI 셸 및 HUD |
| **렌더링** | PixiJS 8 | WebGL 기반 2D 게임 렌더링 |
| **백엔드** | Node.js + Express + Socket.IO | 실시간 멀티플레이어 서버 |
| **음성채팅** | WebRTC | P2P 음성 통신 (Socket.IO 시그널링) |
| **E2E 테스트** | Playwright | 브라우저 자동화 테스트 |

## 실행 방법

### 요구 사항

- Node.js >= 20
- pnpm >= 9

### 설치

```bash
pnpm install
```

### 개발 서버 실행

```bash
# 클라이언트만 실행 (로컬 싱글플레이어)
pnpm dev

# 서버만 실행
pnpm dev:server

# 클라이언트 + 서버 동시 실행 (멀티플레이어)
pnpm dev:all
```

브라우저에서 `http://localhost:3000` 으로 접속합니다.

### 멀티플레이어 참여 방법

1. 1인이 닉네임 입력 후 **방 만들기** 클릭 → 4자리 접속코드 생성
2. 나머지 플레이어가 닉네임 입력 후 **참여하기** → 접속코드 입력
3. 4명이 모이면 방장이 **게임 시작** 클릭
4. 각 플레이어는 입장 순서대로 상/하/좌/우 방향을 담당

### 음성채팅

- 멀티플레이어 게임 중 우측 하단 **음성채팅 켜기** 버튼 클릭
- 마이크 권한 허용 후 자동으로 같은 방의 플레이어와 연결
- 음소거/해제, 개별 볼륨 조절 가능
- 발화 감지 시 초록색 인디케이터 표시

### 조작법

| 키 | Phase 1 동작 | Phase 2 동작 |
|----|-------------|-------------|
| `Arrow Up` | 위로 이동 (고레벨: 좌상) | - |
| `Arrow Down` | 아래로 이동 (고레벨: 우하) | - |
| `Arrow Left` | 왼쪽 이동 (고레벨: 좌하) | 집게 왼쪽 이동 |
| `Arrow Right` | 오른쪽 이동 (고레벨: 우상) | 집게 오른쪽 이동 |
| `Space` | 집기 시도 | 집기 시도 |
| `R` | 게임 재시작 | 게임 재시작 |

### 타입 체크

```bash
pnpm typecheck
```

### E2E 테스트

```bash
# 테스트 실행
pnpm test:e2e

# UI 모드로 테스트 실행
pnpm test:e2e:ui
```

## 핵심 알고리즘

### 미로 생성
Recursive Backtracker (DFS) 알고리즘에 시드 기반 PRNG(`mulberry32`)를 적용하여 동일한 시드로 클라이언트/서버에서 같은 미로를 생성합니다.

### 인형 배치
미로 중앙에서 BFS를 실행하여 최소 거리 이상 떨어진 셀에 인형을 배치합니다. 고레벨에서는 미로 외부에 배치됩니다.

### 겹침 판정 (AABB)
집게 박스와 인형 박스의 겹치는 면적 비율을 계산합니다. 10% 미만이면 실패, 이상이면 해당 비율이 확률로 사용됩니다.

### 카메라 시스템
맵은 화면보다 크며, 카메라가 집게를 lerp로 부드럽게 추적합니다.

## 난이도 구간 (4레벨 간격)

| 구간 | 레벨 | 주요 변화 |
|------|------|-----------|
| 1 | 1-4 | 기본 미로 (7x7), 느린 속도 |
| 2 | 5-8 | 미로 확장 (10x10), 속도 증가 |
| 3 | 9-12 | 미로 (13x13), Phase 2 경로 좁아짐 |
| 4 | 13-16 | 불규칙 테두리, 대각선 전환 시작 |
| 5 | 17-20 | 인형 미로 외부 배치, 강한 드리프트 |
| 6 | 21-24 | 4명 모두 대각선, 매우 좁은 경로 |
| 7 | 25-28 | 복잡한 불규칙 테두리, 최대 드리프트 |
| 8 | 29-30 | 모든 난이도 요소 최대치 |
